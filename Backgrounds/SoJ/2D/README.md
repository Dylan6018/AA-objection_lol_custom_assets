# AA6 courtrooms - 2D alternatives

Ten AI-generated alternative views, matching the approved [standard defense bench](../Standard/2D_test/defense-v1.png). Together these cover the two courtroom sets collected for this repository: five standard views and six Khura'in views.

Generated with the built-in image generation tool on 2026-10-25. Each source view supplied the composition; the approved defense image supplied the 2D style. Full prompts and source paths are in [generation-manifest.json](generation-manifest.json). Original game art and designs belong to Capcom; these generated adaptations are unofficial fan assets.

## Views

- Standard: prosecution, judge, witness, overview (plus the existing defense image linked above).
- Khura'in: defense, prosecution, co-counsel, judge, witness, overview.

Original source assets remain in ../Standard and ../Khura_in with their source credits. New PNGs are saved without rescaling or repainting the tool output. Foreground benches in the images are part of the background, not separate transparent desk layers. The approved standard defense setup uses objection.lol's [AJ] Defense foreground desk; other views may need a suitable desk layer for character occlusion.

In objection.lol, search backgrounds for `2D SoJ`.
